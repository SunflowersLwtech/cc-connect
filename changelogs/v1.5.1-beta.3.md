## v1.5.1-beta.3 — 2026-09-29

Third beta since v1.5.0 stable. This release cherry-picks 8 reviewed PRs onto the tested `v1.5.1-beta.2` baseline instead of publishing the full moving `main` branch.

### New Features
- **Web dashboard** — Manage multi-workspace mode, the workspace base directory, and channel-to-directory bindings from the project detail page (#1772)

### Bug Fixes
- **DingTalk** — Detect quoted and replied-to messages in the rich-text inbound path (#1912)
- **GitHub Copilot** — Include plugin-provided skill roots in agent discovery (#1913)
- **macOS daemon** — Restart an already loaded launchd service in place, avoiding the fragile bootout/reload path (#1915)
- **Feishu** — Download and forward top-level file attachments embedded in rich-text post messages (#1888)
- **Kimi** — Restore current Kimi Code transcript history and installed model discovery, filter injected user records, and honor relocated `KIMI_CODE_HOME` session storage (#1916)
- **Cron** — Humanize `CRON_TZ`/`TZ` expressions and display next/last run times in the schedule's timezone (#1922)
- **Workspace sessions** — Derive per-workspace persistence only when the engine has a real store path, preventing stray `*_ws_*.json` files for memory-only stores (#1926)

### Verification
- Latest `main` aggregate CI passed lint, unit, smoke, regression, and performance jobs.
- Clean release candidate passed Go build, vet, Web production build, five selective-compilation configurations, release-local gates, full race tests, smoke tests, and regression tests.
- Real-channel and real-agent QA begins on this beta; stable promotion still requires an explicit QA pass for the exact beta commit.
