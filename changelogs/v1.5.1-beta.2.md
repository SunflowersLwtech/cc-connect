## v1.5.1-beta.2 — 2026-09-27

Second beta since v1.5.0 stable. This release cherry-picks 20 reviewed PRs onto the tested `v1.5.1-beta.1` baseline instead of publishing the full moving `main` branch.

### Core and Session Reliability
- Use real API-reported input tokens for auto-compress decisions (#1761)
- Lock replacement sessions before releasing the old session during idle reset (#1847)
- Drive auto-compress from exact transcript usage and explicitly gate the heuristic (#1845)
- Add generation-counted busy locks with stale-break recovery and stop-path release (#1838)
- Avoid creating temporary files inside target directories (#1777)
- Synchronize command-registry agent-directory reads and writes (#1662)
- Persist late session IDs even when a turn ends in error (#1901)
- Invalidate stale workspace sessions (#1699)

### Agents
- **Claude Code**: Exclude Stop-hook-rejected drafts from aggregated replies (#1855)
- **Claude Code**: Preserve `AskUserQuestion` in bypass permission modes (#1880)
- **Codex**: Persist the session ID as soon as `thread.started` arrives (#1623)
- **Codex**: Reject concurrent exec turns for the same session while preserving cross-session concurrency (#1881)

### Messaging Platforms
- **Feishu**: Enforce `allow_from` before every card action, including permission approval (#1854)
- **Slack**: Deduplicate the same message delivered through both `app_mention` and `message` subscriptions (#1822)
- **DingTalk**: Route group attachments through the group-message API (#1903)
- **DingTalk**: Forward inline images from rich-text messages (#1626)
- **QQ Bot**: Forward images from quoted messages to agents (#1806)

### Tests and Docs
- Wait for persistence completion before temporary test directories are cleaned up (#1911)
- Add direct tests for `DirHistory` ordering, trimming, persistence, bounds, and isolation (#1663)
- Add the official international Kimi Code link to the English and Chinese READMEs (#1876)

### Verification
- Web production build, Go module verification, and full Go build
- Full `go test ./... -race` suite
- Coverage suite
- Smoke, regression, and performance suites
- Deterministic PR-specific gates for restart/resume, authorization, channel routing, attachments, deduplication, and concurrency
